CareerSync AI Assistant setup
============================

Replace these files in your project:

1) server/app/routers/extension.py
   <- extension.py from this ZIP

2) extension/background.js
   <- background.js from this ZIP

3) extension/content/content.js
   <- content/content.js from this ZIP

Server .env:
------------
Add your Groq key if it is not already present:

GROQ_API_KEY=your_groq_api_key_here

Optional:
GROQ_MODEL=your_current_groq_chat_model
GROQ_API_URL=https://api.groq.com/openai/v1/chat/completions

If GROQ_MODEL is omitted, the code currently falls back to llama-3.3-70b-versatile.
If Groq reports that model as unavailable, set GROQ_MODEL to a model enabled in your Groq account.

No API key is stored in the Chrome extension. The extension calls your FastAPI backend,
and the backend calls Groq.

Restart/test:
-------------

cd C:\Users\Lenovo\job_automation\server
python -m uvicorn app.main:app --reload --port 8000

Then open:
http://127.0.0.1:8000/docs

You should see:
POST /extension/ai/suggest-batch

Chrome:
1. chrome://extensions
2. Reload CareerSync
3. Hard-refresh the job application form page
4. Click Autofill This Form

Expected flow:
Extension Profile -> learned memory -> one batched AI semantic request -> ask user only if unresolved

Example target behavior:
- profile gender = Female
- field question = He/him, choices = Yes/No
- AI should choose No
- field question = She/her, choices = Yes/No
- AI should choose Yes

Safety behavior:
AI does not guess work authorization/sponsorship, disability, veteran status,
race/ethnicity, religion, sexual orientation, marital status, or criminal-history answers.
Those remain explicit user questions unless already stored.
